# 聊天应用测试指南

## 1. 应用程序访问

应用程序已经成功启动，可以通过以下URL访问：
- 本地访问：http://127.0.0.1:5000
- 网络访问：http://10.23.100.170:5000

## 2. 用户系统测试

### 2.1 用户注册
1. 访问登录页面，点击"注册"链接
2. 输入用户名和密码（两次输入相同的密码）
3. 点击"注册"按钮
4. 预期结果：注册成功，跳转到登录页面

### 2.2 用户登录
1. 在登录页面输入注册的用户名和密码
2. 点击"登录"按钮
3. 预期结果：登录成功，跳转到聊天页面

### 2.3 用户退出
1. 在聊天页面点击"退出登录"按钮
2. 预期结果：退出成功，跳转到登录页面

## 3. 聊天功能测试

### 3.1 发送消息
1. 在聊天页面的输入框中输入消息内容
2. 点击"发送"按钮或按下回车键
3. 预期结果：消息显示在聊天窗口中，所有在线用户都能看到

### 3.2 查看在线用户
1. 登录到聊天页面
2. 查看右侧的在线用户列表
3. 预期结果：显示当前所有在线的用户

### 3.3 查看消息历史
1. 登录到聊天页面
2. 查看聊天窗口的内容
3. 预期结果：显示之前的聊天记录

## 4. @功能测试

### 4.1 @天气查询
1. 在聊天输入框中输入：@天气 北京
2. 点击"发送"按钮
3. 预期结果：系统返回北京的天气信息，聊天背景会根据天气类型变化

### 4.2 @60s新闻
1. 在聊天输入框中输入：@新闻
2. 点击"发送"按钮
3. 预期结果：系统返回每日60秒新闻，以图文列表形式展示

### 4.3 @音乐播放
1. 在聊天输入框中输入：@音乐 晴天
2. 点击"发送"按钮
3. 预期结果：系统搜索并返回周杰伦的《晴天》，以音乐卡片形式展示，点击播放按钮可以播放音乐

## 5. 多用户测试

1. 打开两个不同的浏览器窗口
2. 使用不同的用户名登录到聊天应用
3. 在一个窗口中发送消息
4. 预期结果：另一个窗口能实时接收到消息
5. 在一个窗口中使用@功能
6. 预期结果：所有窗口都能看到@功能的结果

## 6. 错误处理测试

### 6.1 注册错误
1. 尝试使用已存在的用户名注册
2. 尝试使用不同的密码和确认密码
3. 预期结果：系统显示相应的错误信息

### 6.2 登录错误
1. 尝试使用不存在的用户名登录
2. 尝试使用错误的密码登录
3. 预期结果：系统显示相应的错误信息

### 6.3 @功能错误
1. 尝试查询不存在的城市天气：@天气 不存在的城市
2. 尝试搜索不存在的音乐：@音乐 不存在的音乐
3. 预期结果：系统显示相应的错误信息

## 7. 性能测试

1. 同时登录多个用户（5-10个）
2. 每个用户发送多条消息
3. 使用@功能查询天气、新闻和音乐
4. 预期结果：应用程序能够稳定运行，没有明显的延迟

# 技术亮点说明

1. **实时通信**：使用Socket.IO实现实时聊天功能，支持多用户同时在线
2. **模块化设计**：将不同功能模块分离，便于维护和扩展
3. **延迟导入**：避免循环导入问题，提高代码质量
4. **响应式设计**：适配不同屏幕尺寸的设备
5. **API集成**：集成天气、新闻和音乐API，提供丰富的功能
6. **数据持久化**：使用SQLite存储用户信息和聊天记录
7. **安全机制**：密码加密存储，用户认证和授权
